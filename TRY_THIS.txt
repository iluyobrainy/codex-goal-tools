Codex Goal Tools quick test

What this is:
This package exposes Codex's native experimental thread goal backend in Codex Desktop through the bundled codex-goal-tools:goal-native skill. It is not a fake goal store.
It exposes compact/auto-compact helpers for long-running goals, but automatic compaction is not enabled by default.

Requirements:
- Codex CLI/Desktop with experimental goals support.
- Python available on PATH.
- A Codex thread opened in the workspace you test from.

Install:
Automatic install from GitHub:

   irm https://raw.githubusercontent.com/iluyobrainy/codex-goal-tools/main/install.ps1 | iex

Manual install:
1. Add this folder as a local plugin marketplace:

   codex plugin marketplace add "<path-to-this-folder>"

2. Install/enable "Codex Goal Tools" from the plugin list.

3. Restart Codex Desktop if the skill does not appear immediately.

4. Run setup in Codex Desktop:

   $goal-native setup

   This safely ensures ~/.codex/config.toml contains:

   [features]
   goals = true

   It does not add automatic compaction settings. If you previously installed a version that added them, run:

   $goal-native disable-auto-compact

   It also installs the global ~/.codex/AGENTS.md rule that tells future threads to reopen Waiting for next goal after completing a real goal and to read local goal-pack files for long pasted goals.

   If setup changes an existing config file, it writes a timestamped .bak backup first.

Test in Codex Desktop:
- Type: $goal-native status
- Or use the explicit plugin skill name if shown: $codex-goal-tools:goal-native status

Expected result:
- _native_goal_backend: true
- goal: none, or your current active goal

Direct backend smoke test:
Run this from a workspace that has a Codex thread:

   python "<path-to-this-folder>\plugins\codex-goal-tools\scripts\goal_backend.py" setup --workspace "<your-workspace-path>"
   python "<path-to-this-folder>\plugins\codex-goal-tools\scripts\goal_backend.py" bootstrap --workspace "<your-workspace-path>"
   python "<path-to-this-folder>\plugins\codex-goal-tools\scripts\goal_backend.py" smoke-test --workspace "<your-workspace-path>"
   python "<path-to-this-folder>\plugins\codex-goal-tools\scripts\goal_backend.py" auto-compact --workspace "<your-workspace-path>"
   python "<path-to-this-folder>\plugins\codex-goal-tools\scripts\goal_backend.py" install-pill-rule --workspace "<your-workspace-path>"
   python "<path-to-this-folder>\plugins\codex-goal-tools\scripts\goal_backend.py" disable-auto-compact --workspace "<your-workspace-path>"

Expected result:
- ok: true
- _native_goal_backend: true
- verifiedObjective matches setObjective
- For auto-compact, _native_compact_backend: true and compactStarted: true when Codex accepts the compaction request.

Note:
Native compaction is itself a Codex turn. Run auto-compact at an idle checkpoint before continuing goal work; it cannot safely interrupt an already-running model turn.

Set a test goal:

   python "<path-to-this-folder>\plugins\codex-goal-tools\scripts\goal_backend.py" set --workspace "<your-workspace-path>" --goal "Test native goal bridge"

Set a long pasted goal pack without losing text:

   Get-Content ".\goals.txt" -Raw | python "<path-to-this-folder>\plugins\codex-goal-tools\scripts\goal_backend.py" set --workspace "<your-workspace-path>" --goal-stdin

If the text is over the native backend limit, the bridge stores the full paste in ~/.codex/goal-packs/ and sets the visible native goal to a short pointer. Use /goal1, /goal2, etc. inside the pasted text when you want ordered goal sections.

Clear it:

   python "<path-to-this-folder>\plugins\codex-goal-tools\scripts\goal_backend.py" clear --workspace "<your-workspace-path>"
